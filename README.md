## 手机设置

1. 小火箭先导入与电脑相同的机场订阅，保留节点原名。
2. 首页点 +，类型选 HTTP，名称填写“🇹🇼 台湾独立静态出口”。地址、端口、用户名、密码填商家提供的值，仅保存在手机本地。
3. 配置页面添加上面的永久地址，下载并使用；首页“全局路由”选“配置”。
4. 静态节点的 ⓘ → 代理通过／代理链，选择分组“🔗 静态出口中转”，保存。首页选中静态出口本身。
5. 在代理分组里切换“🔗 静态出口中转”的机场成员。路径：手机 → 所选机场中转 → 台湾静态出口 → 网站。

如果手机节点名称不同，先恢复同一机场订阅的原始名称，或在分组里重新选择对应节点。配置不会凭空生成机场账号。

## 分流与验证

- 国内、局域网、苹果和微软常规服务直连。
- GitHub/Copilot 优先代理，其余海外 TCP 通过台湾静态出口；剩余海外 UDP 拒绝。
- 切换中转后检查最终出口仍是购买的台湾 IP。
- 国内直连目标仍可能看到真实出口，关闭 VPN 后的系统断网保护不由此文件保证。

Windows 防火墙、TUN 和系统设置不能移植到 iOS。PASS-RULE 是 Mihomo 内核占位项，不是真实节点；private 清单中的单标签域名正则未移植，详见 rules/manifest.json。静态校验不等于手机原生导入和网络实测。

完整分组快照见 public-mirror-manifest.json；来源和许可见 UPSTREAM.md。机场增删节点或改名后需重新同步。claude-guard.conf 和 claude-guard-2.2.92.conf 是旧版模板，新导入使用 desktop-public.conf。
